The excuse a hardware wallet gives for refusing to sign a transaction at 3 AM — written by `main.ts` to `/output/entry.txt` for the [The 3 AM Excuse](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878) bounty on [make.fun](https://make.fun).

## Run

```sh
node main.ts
cat /output/entry.txt
```

## Entry

> It's 3 AM. I don't sign transactions after midnight — even my private keys have a bedtime, and your judgement went to sleep hours ago.
